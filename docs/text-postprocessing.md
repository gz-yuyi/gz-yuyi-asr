# 转写文本后处理模式

实时转写和离线转写使用同一组文本后处理模式。离线 JSON 创建任务接口使用 `NumberNormalizationMode`、`FillerFilterMode`、`ProfanityFilterMode`；离线上传接口和实时 WebSocket 使用对应的 snake_case 字段 `number_normalization_mode`、`filler_filter_mode`、`profanity_filter_mode`。两种命名的取值和效果完全相同。

服务端按“数字转换 → 语气词过滤 → 脏词过滤 → 标点清理”的顺序处理每段识别文本。模式只处理已经识别出的文字，不会改变音频识别过程。以下表格列出的值是客户端可依赖的受支持取值；请勿传入其它整数。

## 数字转换模式

`number_normalization_mode` / `NumberNormalizationMode` 控制中文数字表达是否转换为阿拉伯数字等书面形式。

| 模式 | 名称 | 行为 |
| :---: | :--- | :--- |
| `0` | 不转换 | 不执行数字转换，保留模型识别出的中文数字文本。 |
| `1` | 智能转换（默认） | 按上下文保守转换高置信度数字表达，包括编号、日期、时间、百分比、金额与常见计量单位、序数、道路/房间号，以及“洞、幺、两、拐、勾”等通信数字读法；会保护可能表示约数、固定词语或专名的表达，降低误转风险。 |
| `3` | 数学与数字串增强转换 | 包含模式 `1` 的规则，并额外转换分数、数学运算上下文，以及更像逐位读数的混合数字串。适合公式、口述编号等希望更积极转换数字的场景。 |

典型效果：

| 输入文本 | 模式 `0` | 模式 `1` | 模式 `3` |
| :--- | :--- | :--- | :--- |
| `二零二六年四月十六日十五点三十分支付五百二十元` | 原样保留 | `2026年4月16日15:30支付520元` | 同模式 `1` |
| `订单号二零二六零四一六零零一` | 原样保留 | `订单号20260416001` | 同模式 `1` |
| `警号洞幺两三四五六拐八勾` | 原样保留 | `警号0123456789` | 同模式 `1` |
| `三分之一加负五点二等于二` | 原样保留 | 原样保留 | `1/3加-5.2等于2` |
| `四二十六分`（逐位读数） | 原样保留 | 原样保留 | `4216分` |
| `三四天后参加五四运动` | 原样保留 | 原样保留 | 原样保留 |

> [!NOTE]
> 数字转换采用上下文规则而不是无条件替换。模式 `3` 比模式 `1` 更积极，但仍会保留已知固定表达和明显约数；它不等同于“把所有中文数字字符逐字替换”。

## 语气词过滤模式

`filler_filter_mode` / `FillerFilterMode` 控制是否删除口语中的语气词和话语填充词。

| 模式 | 名称 | 行为 |
| :---: | :--- | :--- |
| `0` | 不过滤（默认） | 保留全部语气词。 |
| `1` | 基础过滤 | 删除短语气词：`嗯`、`呃`、`额`、`啊`、`哦`、`唉`、`诶`、`欸`、`嗯嗯`、`呃呃`。 |
| `2` | 扩展过滤 | 删除模式 `1` 的词，并额外删除独立出现的常见填充短语：`那个`、`这个`、`就是说`、`就是`、`然后`、`你知道`、`对吧`、`是吧`、`怎么说`、`怎么说呢`。 |

示例输入：`嗯，我们，那个，方案，就是说，再确认。`

| 模式 | 输出 |
| :---: | :--- |
| `0` | `嗯，我们，那个，方案，就是说，再确认。` |
| `1` | `我们，那个，方案，就是说，再确认。` |
| `2` | `我们，方案，再确认。` |

基础短语气词紧邻中文正文时也可以被删除；模式 `2` 新增的多字填充短语只在句首、句尾或空格/标点分隔的短语边界上匹配，避免误删正常词组中的相同文字。删除后服务端会执行通用标点清理，包括合并相邻重复标点，以及清理由删除操作留下的部分句首或句尾逗号。

## 脏词过滤模式

`profanity_filter_mode` / `ProfanityFilterMode` 控制命中内置脏词表后的输出方式。

| 模式 | 名称 | 行为 |
| :---: | :--- | :--- |
| `0` | 不过滤（默认） | 保留命中的脏词原文。 |
| `1` | 删除 | 删除命中的完整脏词。 |
| `2` | 遮盖 | 将每个命中的完整脏词替换为一个半角星号 `*`，不按原词字数重复星号。 |

示例输入：`这也太妈的离谱了。`

| 模式 | 输出 |
| :---: | :--- |
| `0` | `这也太妈的离谱了。` |
| `1` | `这也太离谱了。` |
| `2` | `这也太*离谱了。` |

脏词按内置词表进行完整词条匹配；同一位置可能匹配多个词条时优先处理最长词条。当前词表主要覆盖常见中文辱骂表达，词表可能随服务版本扩充。需要保留逐字稿原貌时使用模式 `0`；需要可见地标记过滤位置时使用模式 `2`。
